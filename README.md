# PortSwigger Web Security Academy Labs

**Author:** Yash Bhure  
**Focus:** Web Application Security | Ethical Hacking | Penetration Testing

## Overview

This repository documents my hands-on journey through [PortSwigger Web Security Academy](https://portswigger.net/web-security), solving practical web security labs and documenting the techniques, vulnerabilities, exploitation workflows, and remediation strategies involved.

My goal is to develop practical skills in web application penetration testing, HTTP traffic analysis, vulnerability discovery, and secure application development.

## Tools & Technologies

- Burp Suite Community Edition
- Kali Linux
- VMware Workstation
- Chrome / Chromium
- HTTP and HTTPS analysis
- OWASP web security concepts

## Learning Methodology

For each lab, I aim to document:

1. Vulnerability overview and root cause
2. Application behavior and attack surface
3. Request interception and analysis using Burp Suite
4. Proof of concept and exploitation steps
5. Evidence and observations
6. Impact and remediation recommendations
7. Key takeaways

## Disclaimer

This repository is intended for educational purposes and authorized security testing only. All practical exercises are performed within PortSwigger Web Security Academy's intentionally vulnerable lab environments.
